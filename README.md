# OS1-projekat
Functional kernel designed for RISC-V architecture, which is executed with QEMU emulator.
It handles tasks such as:
 - Memory Allocation
 - Threads
 - Interrupts
 - Semaphores
 - I/O
 - ...

Full specification is given within **[Project_Requirements.pdf](./Projektni_zadatak_2024._v1.0.pdf)**
